How to Self-Host n8n Cheap (2026): Step-by-Step on a $4.50 VPS

Short answer: rent a 2 vCPU / 4GB VPS from Hetzner (about 4.50 to 5 dollars/mo) or Hostinger (about 6.49 to 8.99 dollars/mo intro rate), install Docker, run n8n's official one-line installer, and point a domain at it with a free Caddy or Nginx reverse proxy for HTTPS. Total time: 30-60 minutes the first time. Total cost: under 5 dollars a month with unlimited workflows and executions, versus 24 dollars/mo minimum for n8n Cloud Starter's capped 2,500 executions.

The direct answer / TL;DR steps

  1. Rent a VPS with at least 2GB RAM (4GB is safer if you will run AI-heavy workflows) -- Hetzner CX22 or a similar budget KVM box.
  2. SSH in, install Docker if it is not already on the image.
  3. Run n8n's official installer: curl -fsSL https://get.n8n.io | sh -- this creates a folder, writes a compose file and .env with generated secrets, and starts the container.
  4. Point a domain's A record at your VPS IP, then put Caddy or Nginx in front for free automatic HTTPS (n8n needs HTTPS for webhooks and OAuth logins to work properly).
  5. Log in at your domain, set up your owner account, and start building. Update later with curl -fsSL https://get.n8n.io | sh -s -- --upgrade.

1. Create the VPS. Pick Ubuntu 22.04 or 24.04 as the OS image, 2 vCPU / 4GB RAM minimum. Note the IP address you are given.

2. SSH in and update packages first.

3. Run the n8n installer. As of the 2026 release line, n8n recommends its one-line install command over the older manual Docker Compose file -- it checks for Docker, creates an n8n folder, writes a compose file and .env with generated secrets, and starts the container automatically. First run pulls the image and can take a few minutes.

4. Point your domain at the box. Add an A record for a subdomain like n8n.yourdomain.com pointing at the VPS IP. Put a reverse proxy (Caddy is the simplest -- it handles HTTPS certificates automatically with almost no config) in front of port 5678 so you are not exposing n8n over plain HTTP.

5. Open the URL, create your owner account, and you are running. Set a calendar reminder to run the upgrade command monthly -- n8n ships frequent updates and skipping too many at once makes the jump riskier.

Common failure points

  • Skipping HTTPS. Webhooks, OAuth logins for connected apps, and some community nodes silently misbehave over plain HTTP. Set up the reverse proxy before you rely on this for real workflows.
  • Running on 1GB RAM. n8n plus its task runners can OOM-kill your own workflows on the smallest VPS tiers, especially with AI or data-heavy nodes. 4GB is the safer floor, not the minimum listed spec.
  • Forgetting backups. Your workflow data lives in a Docker volume on that one box. If the VPS dies and you never set up backups, everything you built is gone. Most VPS hosts offer a cheap weekly snapshot add-on -- turn it on.
  • Letting updates pile up. n8n does not break often, but jumping from a 6-month-old version straight to current can hit multiple breaking changes at once. Update monthly in small steps instead.
  • No monitoring. Self-hosted means nobody pages you when it goes down. A free uptime checker pinging your n8n URL is a 5-minute setup that saves you from finding out your automations died three days ago.

FAQ

What is the cheapest way to self-host n8n?

A raw VPS running Docker is the cheapest route -- Hetzner CX22 runs about 4.50 to 5 dollars per month for 2 vCPU and 4GB RAM, enough for a solo builder running n8n Community Edition with unlimited workflows and executions. Managed one-click n8n hosts run 4 to 8 dollars per month if you want to skip the Docker setup entirely.

Is self-hosting n8n actually free?

The n8n Community Edition software itself is free and open-source with no license fee, unlimited workflows, and unlimited executions. You still pay for the server it runs on, which is why self-hosting costs 4 to 9 dollars a month rather than literally zero, unless you already have a spare machine or free-tier VPS credit sitting around.

Do I need to know Docker to self-host n8n?

Basic comfort with the command line helps, but n8n's own one-line installer handles Docker Compose, config files, and starting the container for you. If you have never used SSH before, budget an evening the first time rather than the 30 minutes some guides promise.
